How to install in Gmail
  1. Click just before the N of NEURO-CODEZ and drag to the end of “Facebook”, so the logo is included. Copy with Ctrl+C.
  2. Gmail → Settings (gear) → See all settings → General → Signature → Create new.
  3. Paste with Ctrl+V, then set it as the default for new emails and replies.
  4. Save Changes at the bottom of the page — it is easy to miss.

The logo is embedded in the file rather than linked, so Gmail uploads its own copy on paste. Nothing depends on your Render service being awake.
